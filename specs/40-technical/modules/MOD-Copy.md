## Responsibility
The single place the tool gets user-facing text. Strings are generated at build time from
`specs/30-experience/copy.md` into a typed lookup (one COPY ID → one string per supported language,
with plural forms, RULE-17) so the UI never hard-codes wording and the text stays in sync with the
specs. It holds the active language (set by MOD-Host); `t()` and the formatters use it: zoom
percentages, pixel sizes (`{width} × {height}`), counts and plurals via `Intl.NumberFormat` and
`Intl.PluralRules` (F-018.R6). It never formats anything that goes into the export (INV-05).

## Not responsible for
- Any behaviour, state, or layout — it only resolves IDs to text.
- Deciding when a message is shown (MOD-App, MOD-Canvas).

## Public surface
- A typed `t(key, params?)` lookup covering every COPY string in copy.md, generated by MOD-Build.
- Number, size and count formatters for the active language.
- The active-language signal.

## Implements
30-experience/copy.md; F-013.R3, F-018.R1/R6; RULE-17. Decided by ADR-0013, ADR-0015.
