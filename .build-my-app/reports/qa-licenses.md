## Findings

### Blocker

### Major

### Minor
1. **DEP-07 approval condition unmet.** Status reads "approved (...; record the pinned portal commit)" but no portal commit is recorded in `dependencies.md`, `specs/30-experience/tokens.json` or its docs. Provenance is the owner's own work, so there is no licence risk. Record the commit, or drop the condition.
2. **Test fixtures are not registered.** `tests/fixtures/*` (16 files) plus `tools/exif_orient.py` are not DEP rows, though ADR-0001 rule 4 says "every asset pack". They are generated by `make-fixtures.sh` (ImageMagick, own pattern), contain no ICC/Apple/copyright strings (checked), and do not ship. Add one "test fixtures (own work, generated)" row for provenance. This matters if wide-gamut fixtures are added later (ADR-0018 flags Apple ColorSync profiles).
3. **Registry prose is stale.** The intro says every row is `proposed` until the audit approves it. The notes still say "DEP-19 waits for the real lockfile". Both are contradicted by the table (all approved; DEP-19 approved 2026-11-02). Fix the wording.
4. **Notices file is not offline-reachable and has a cosmetic OFL slip.**
   - `dist/sw.js` has no reference to `/third-party-notices.txt`, so it is probably not precached. The attribution is still served with the deploy, but offline users cannot open the link. Confirm against ADR-0024's seed list.
   - The JetBrains Mono copyright line includes a stray "JetBrainsMono-Italic[wght].ttf: Copyright..." fragment from the Fontsource licence file. Italic is not shipped. Harmless.

### Notes (no action required)
- Token `--tk-font-family-display: Unbounded` is declared but unused, and no Unbounded file ships. If it is ever shipped, register it.
- `pnpm licenses` only sees platform packages installed here (lightningcss-darwin-arm64). The lockfile also lists other-platform lightningcss builds (same MPL-2.0 family, dev only). Not audited from metadata. Only reachable in dev, not in `dist/`.
- Local Playwright cache holds Firefox and several Chromium/WebKit builds (DEP-17 says no Firefox). That is machine state, not repo content. The browsers are test-only and not distributed.
- Legal review is advisable for: (a) the OFL view that Fontsource's woff2 subsetting of the fonts is a permitted "Modified Version" (neither font declares a Reserved Font Name in its notice); (b) the MPL-2.0 "unmodified, never shipped" reliance. Both look fine to me but I am not a lawyer.
- No network was used. Licences came from installed package metadata and licence files. The registry's `latest on registry` re-verification was not repeated.
